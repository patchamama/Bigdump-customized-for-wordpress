## Specs
S1: "Para hacer las pruebas puede instalar aquí un wordpress antiguo y a partir de este hacer varias pruebas."
S2: "si se ejecuta en un lugar en que no hay ningún cms instalado, que brinde la opción de instalación de cualquiera de los cms soportados en la misma carpeta en que se encuentra o en un sandbox y que permita entonces hacer pruebas con este."
S3: "También si hubiera un cms en un sandbox que brinde opción de migrarlo a la carpeta actual en que se encuentra la app."
S4: "Claro que en la instalación se haría progresivamente y la app comprobaría sí está instalado mysql, mariadb o postgresql, y en dependencia del cms elegido brindar las bases de datos que lo soportan a elegir una,"
S5: "después poner usuario y contraseña de acceso, prefijo (brindando una propuesta tras comprobar que no está siendo usado en la base de datos) o sí se pone un prefijo que ya existe, proponer usar esa base de datos con sus datos en una instalación fresca y así continuar con los próximos pasos,"
S6: "como también elegir plugins a instalar (proponer algunos útiles),"
S7: "opciones relacionadas con el htaccess como las urls amigables (comprobando antes en sandbox que estos cambios no rompen el cms),"
S8: "templates a usar y entre ellos proponer en caso de wordpress de pago Divi 4,divi 5 y element pro y si se brindan los datos de acceso a estos que se haga la instalación completa (a no ser que brinden la opción de prueba)."
S9: "También si se detectara un archivo de configuración junto con la app y no hay nada instalado de cms pero se detecta el cms asociado a ese archivo de configuración (wp-config.php, configuration.php,...) deseo se brinde la opción de instalación fresca y limpia de ese cms usando la configuración del archivo de configuración en que claro, la conexión con la base de datos debe de ser correcta y mejor hacer copia de todos los datos en unas nuevas tablas con nuevo prefijo para no sobreescribir la instalación anterior y hacer instalación completa nuevamente fresca a partir de ahí (si el instalador detecta en la base de datos plugins instalados originalmente, volver a instalarlos en su versión más reciente)."
S10: "Documentar todas estas situaciones en el README"
S11: "También permitir reemplazo explícito"
